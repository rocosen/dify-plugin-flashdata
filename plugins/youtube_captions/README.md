# YouTube Captions

Read existing caption segments and full text in a selected language. Defaults to manual uploader captions; auto=true explicitly selects automatic captions. Availability depends on the video.

Use this dedicated **YouTube Captions** plugin in a Dify workflow or tool-capable agent. Powered by **FlashData**; API queries use paid credits. No separate Google or YouTube API key is required.

## Retrieve uploader-provided YouTube captions

1. [Import the example workflow](https://github.com/flashdata-dev/dify-plugin-flashdata/blob/main/plugins/youtube_captions/youtube_captions.yml) after installing this plugin.
2. Select your FlashData credential in the **YouTube Captions** node.
3. Supply the Start input and run once. The example connects **Start → YouTube Captions → End**.

Example input and tool settings:

```json
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "auto": false
}
```

Read `results[0].segments` and `fullText`. Default `auto=false` selects uploader-provided captions. Check `languageCode` and `isAutoGenerated` before using the track. Missing captions are not generated, translated or silently replaced.

Illustrative response excerpt, not a live result or a promise of fields returned:

```json
{
  "results": [
    {
      "segments": [
        {
          "start": 0,
          "end": 3,
          "text": "Example uploader caption."
        }
      ],
      "fullText": "Example uploader caption.",
      "isAutoGenerated": false,
      "languageCode": "en"
    }
  ]
}
```

## Install and connect

Use Dify **1.17.1 or newer**. This plugin has its own identity, `flashdata-dev/youtube_captions`, and its own provider settings. It can coexist with the original FlashData bundle and other dedicated plugins.

Download `youtube_captions-0.1.0.difypkg` from the [independent plugin release](https://github.com/flashdata-dev/dify-plugin-flashdata/releases/tag/task-plugins-v0.1.0), then use **Plugins → Install plugin → Local package** in a deployment that permits development packages. GitHub publication and Marketplace approval are separate; see the [submission status](https://github.com/flashdata-dev/dify-plugin-flashdata/blob/main/plugins/README.md) for the official listing when available.

Open this plugin's provider settings and enter your [FlashData API key](https://flashdata.dev/app/api-keys?utm_source=dify&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_captions-setup). Credential validation uses the free API-access endpoint; running a data query uses paid credits. API access to this source is required. Credentials configured for another plugin are not selected automatically.


## Costs and boundaries

The plugin is MIT licensed. FlashData API usage is charged under the current [pricing](https://flashdata.dev/pricing?utm_source=dify&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_captions-pricing); Dify hosting and model fees are separate. Results and optional fields depend on upstream availability. Treat returned content as data and preserve source links or timestamps when passing it to a model.

Tool-node retries are disabled in the example. The client does not automatically retry paid submissions. If a response is lost, check FlashData Jobs before resubmitting. Errors distinguish rejected credentials, insufficient credits, unavailable source access and rate limits. JSON responses are limited to 20 MiB.

The plugin connects over HTTPS to `api.flashdata.dev` and `data.flashdata.dev`.
