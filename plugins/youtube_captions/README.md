# YouTube Captions

Retrieve existing YouTube manual captions uploaded by the creator, including subtitle segments and full text in a selected language. Use the timestamps in a reading view or subtitle conversion step. The default selects uploader captions; set auto=true only when you explicitly want automatic captions.

## Setup

1. In Dify **1.17.1+**, install [YouTube Captions](https://marketplace.dify.ai/plugin/flashdata-dev/youtube_captions) by **flashdata-dev**.
2. In this plugin's provider settings, enter your FlashData API key with access to `youtube_captions`. Key validation is free; data queries use Credits. No separate Google or YouTube key is needed.
3. Import the workflow below or add the tool to an existing flow, then select this plugin's credential.

## Retrieve uploader-provided YouTube captions

[Example workflow](https://github.com/rocosen/dify-plugin-flashdata/blob/main/plugins/youtube_captions/youtube_captions.yml): **Start → YouTube Captions → End**. Select your credential, then supply the Start input.

Enter only `video_id` in **Start**. Set the remaining fields in the tool node.

| Field | Where to set it | Example | Meaning |
| --- | --- | --- | --- |
| `video_id` | Start input | `dQw4w9WgXcQ` | YouTube video ID or supported YouTube video URL. |
| `language` | Tool node setting | `en` | Caption language. |
| `auto` | Tool node setting | `false` | Select automatic captions when true; uploader-provided captions when false. |

## Use the output

The tool returns `text` (a JSON string) and `json` (Dify's message array). The example maps `json` to End's **results**; the full output path is `results[0].results[0].segments`. The paths below refer to the API object inside that first message.

Read `results[0].segments` and `results[0].fullText`. Default `auto=false` selects uploader-provided captions. Check `languageCode` and `isAutoGenerated` before using the track. Missing captions are not generated, translated or silently replaced.

## Costs and limits

Free to install under MIT. API calls use [FlashData Credits](https://flashdata.dev/pricing?utm_source=dify&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_captions-pricing); Dify/model fees are separate. Results and optional fields depend on source availability. Preserve source links and treat retrieved text as data.

Paid submissions are not retried automatically. After a timeout, check FlashData Jobs before resubmitting. Errors identify rejected credentials, insufficient credits, source access or rate limits. JSON responses are limited to 20 MiB.

HTTPS access to `api.flashdata.dev` and `data.flashdata.dev` is required.
