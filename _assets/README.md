# Task-plugin icons

The six Google plugins use the color Google G; the nine YouTube plugins use the red YouTube play icon. The aggregate FlashData bundle keeps its existing icon.

Sources retrieved on 2026-11-17:

- Google: https://upload.wikimedia.org/wikipedia/commons/c/c1/Google_%22G%22_logo.svg
- YouTube: https://upload.wikimedia.org/wikipedia/commons/0/09/YouTube_full-color_icon_%282017%29.svg

Only SVG viewport dimensions and presentation attributes were normalized for standalone rendering. Logo shapes and colors are preserved. These third-party marks identify supported services; FlashData remains the API provider and flashdata-dev remains the plugin publisher.
